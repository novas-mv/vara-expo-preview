The system, as it is actually built

Every value below is read out of system/tokens.css when this page is built, and the components are the real ones from system/tw.css. It is generated, not written — so it cannot describe a system the code does not have. 72 tokens across 10 groups.

This page is not a template. There is no pages/design-system/; it is emitted into the published site by tools/build-design-system.py, the way templates.html is. Editing it means editing the generator.

Zone identity

A zone is a string, never a colour. Put data-zone on <body> or a section and --accent follows, and with it every tag, marker, line and field. Store "coral", never #FF8A66.

The buttons go to the foundries. The font files are not hosted here: the site loads them from Fontshare and Google Fonts and keeps no local copy, so offering them for download would mean republishing someone else's binaries from this domain. Both licences are permissive, so that can be done — but it should be a decision, not a side effect of a build script.

Each family also has a metric-matched fallback declared on the landing page — local Arial or Menlo with size-adjust and ascent/descent overrides tuned so the substitute occupies nearly the same space. That is what stops the layout shifting when the webfonts arrive, and what makes a failed font load degrade quietly instead of reflowing the page.

The contracts

Rules that are enforced by a tool, not merely documented. Each one exists because it was broken at least once.

The nav is one component

system/nav.css holds its CSS, system/nav.js its behaviour, tools/normalise-shell.py its markup. Nothing about the nav is declared on a page. It was split four ways once and a page-local copy, being unlayered, outranked the shared one.

The bleed contract

A decorative line may bleed anywhere on the page background but must be clipped only by a full-bleed host, and never with overflow-clip-margin — it widens the clip on every axis and leaks horizontal overflow back in. Enforced by tools/check-bleed.py.

One stroke ladder

68 / 56 / 44, rank 0 first, with --rung-scale taking every rung to 0.6 below 640px. One ladder, not one per context: weight is a constant pixel value, so a rank-0 rung is 4.7% of a desktop and 18.4% of a phone.

Accents are identity, not UI

The four zone hues name a zone. They are never button fills or link colours. .ztag is the single sanctioned exception, and it uses --coral-tag with --tag-ink for its own contrast.

No raw values in page CSS

No hex, no bare clamp(), no Tailwind arbitrary values. If there is no token, snap to the nearest one. This is what stops the system leaking back out into the pages.

Layer discipline

Components are imported into Tailwind's components layer so utilities can still win. An unlayered rule beats every layer whatever its specificity — which is how a one-character * reset once outranked the entire system on one page.
